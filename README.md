# kayito - Mu Launcher

## - Language: C#

## - Framework: .NET Framework 4.8 using WinForms

## - Content:
- Encoder

Used to save launcher information (window name, mutex, updates URL, panel URL, etc.) in an encrypted file.

- Generator

Used to load Launcher.exe and the folder containing all the files to be updated. A .zip file will be generated with this content, along with a .json file containing information about all these files for comparison and updating.

- Updater

It must always be run before the launcher, as it is responsible for reading the encrypted file generated by the Encoder, connecting to the hosting, and downloading the .json file. It then compares the version of Launcher.exe with this file and updates it (if necessary). Finally, it will run Launcher.exe, passing the encrypted file and the .json file as arguments.

- Launcher

It must always be run from the Updater, as it will receive the encrypted file and the .json file containing information about all the files to be checked. It will check each file listed in the .json file and list those that need to be updated. Finally, it will download and update the listed files.
